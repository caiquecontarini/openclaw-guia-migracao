# 01 — Como Conectar ChatGPT / GPT-5.5 ao OpenClaw

## Atualizacao Urgente (Abril 2026)

Saiu o ChatGPT 5.5 e esta incrivel. Atualize seu OpenClaw urgente.

### Prompt para atualizar (cole no seu agente)

Atualize meu OpenClaw para usar o GPT-5.5 como modelo padrao.

Faca nesta ordem:
1. atualize para a versao mais recente;
2. reinicie o Gateway;
3. mude o modelo padrao para openai-codex/gpt-5.5;
4. confirme no status que o modelo ativo ficou mesmo openai-codex/gpt-5.5;
5. reinicie o Gateway de novo para garantir que a troca foi aplicada corretamente.

Antes de concluir, me mostre o status final.

---

## Passo a Passo Manual (via terminal da VPS)

1. Abra o terminal da sua VPS
2. Digite: openclaw config
3. Va em Local > Model > OpenAI > OpenAI CODEX
4. Abra o link de autenticacao no navegador
5. Copie a URL da pagina de erro e cole no terminal
6. Pronto! Agente configurado com ChatGPT
